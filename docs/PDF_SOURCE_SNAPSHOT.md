# PDF 提取的有界源快照

## 本轮修复

PDF 核心检查先打开一次文件，再从该已打开的 reader 最多读取 **64 MiB + 1 字节**。实际读取缓冲区超过 64 MiB 就拒绝；否则在同一缓冲区核对 `%PDF-` 签名，把实际长度写入 `Inspection.bytes`，并交给固定版本 `pdf-extract 0.12.1` 的 `extract_text_from_mem`。提取器不再重新打开路径。DOC / DOCX 的读取、预检和解析路径没有改变。

旧路径先从文件句柄检查长度 / 签名，再让 `extract_text(path)` 重新打开路径。保留的调查在 scratch 符号链接中交替指向两份未修改 Mozilla PDF，第三次检查出现：报告 105,779 字节，但正文属于另一份 32,408 字节文件。两份原件 SHA-256 前后相同。该结果证明检查对象与解析对象可能不一致；**没有演示超限文件绕过，也不把它写成已验证的大小绕过攻击**。

旧调查保存在 `tmp/pdf-gap-investigation/source-snapshot-race.json`，使用当时的 `empty-font-final-cli`；最近发布的 `cell-colors-final-cli` 保持同一 PDF 旧实现，本轮稳定输入的旧 / 新对照使用后者。竞态调查是历史证据，确定性的 opened-handle 单元测试才是本轮修复门禁，不以反复竞态碰运气代替测试。

## 错误与资源边界

- `inspect` 保持严格：加密或损坏 PDF 的提取器错误仍为错误
- `inspect_for_preview` 只将提取器返回的错误转成空正文与 `text_error`；读取、签名、超限错误仍直接拒绝。预览候选不等于有效 PDF
- 无文字的有效 PDF 保留空正文提示，但没有虚假的 `text_error`
- 内存与路径 API 在固定依赖中共用默认解析选项、`maybe_decrypt` 与 `output_doc`；没有新增密码处理、字体映射、正文排序或规范化
- 64 MiB 是输入字节上限，不是解压后内存 / CPU 上限。此修改不捕获第三方提取器 panic，也不替代现有桌面 worker 的隔离 / 截止保护
- “快照”指读完后交给校验和解析的同一字节缓冲区。其他进程若在读取期间原地修改同一文件，仍可能读到混合内容；没有文件锁或原子文件系统快照保证
- 桌面 `read_current_pdf` 之后还会重开路径。Rust 提取结果与稍后的 PDF.js 预览仍可能来自不同版本；跨 IPC / 预览会话的源身份绑定是另一个未解决问题

## 确定性回归

`src/pdf_snapshot.rs` 内 13 项检查覆盖：打开 A 后改名并在原路径放 B、打开后删除路径（两种策略均仍解析 A）；读取前增长 / 缩小（包括先观察到超限长度再缩小）后的实际字节数；增长到超限仍拒绝；原地改变签名按实际读取内容拒绝；无限 reader 精确只消费上限 + 1；恰好 64 MiB 的长度 / 签名验证接受（不解析该合成大缓冲区）；完整有效前缀之后 I/O 错误不降级；逐字节短读取；空 / 残缺 / 非法签名；损坏和两份已加密 fixture 的严格 / 预览政策；有效空白 PDF。

这些测试只改变隔离临时目录中的自制文件。真正原件不改名、不改字节；公开路径入口的既有 PDF / 加密 / 损坏 / 源不变检查随核心全量执行。

## 真实文件与独立读取

来源和固定 SHA-256 / Git blob 见 `scripts/pdf-snapshot-corpus.json`；六份 Mozilla PDF 语料原件按原样使用，包括一篇已发表论文与五份上游测试样本，不把它们统称为用户生产文档，也不为适配提取器改造。`scripts/check-pdf-snapshot.py` 使用 pypdf 与 Poppler 独立读取，并把最近发布 CLI 与本轮 CLI 的完整成功 JSON（仅排除耗时）及原始正文逐字节比较；错误按退出码和明确诊断核对。输入与两个 CLI 前后都核对散列，输出写到新目录。

四份原件的旧 / 新正文已核对为完全相同；另外两份 `mixedfonts.pdf` / `noembed-sjis.pdf` 的 `UniJIS-UTF16-H` / `90ms-RKSJ-H` 在旧提取器已经触发不支持编码 panic。本轮不把同样失败算成成功读取，也不声称修复中文映射。Poppler 在这两份原件中提取出对应文字，pypdf 对相应部分仍有告警 / 误解码；不能把任何单个读取器当作所有文字的正确性标准。复杂阅读顺序、连字映射和扫描件 OCR 仍是独立缺口。

准确命令、结果计数、散列与证据目录见 [REGRESSION.md](REGRESSION.md)。本轮是核心源安全修复，不代表浏览器、WebView2 或物理界面的新验收。
