# 单节页面尺寸与正文边距

新增受审计的单节 DOCX 页面尺寸/四边正文边距，以及编辑器中的纸张、方向、边距控件。设置保存到草稿、撤销/重做、另存 DOCX 和可信重开；打印副本和原生 PDF 参数使用同一组显式几何。原生 Windows/WebView2、实际浏览器布局及系统打印本轮仍未验收，独立 LibreOffice 证据不能替代这些验收。

## 模型与历史契约

可选的根属性 `doc.attrs.pageGeometry` 恰含六个整数 twip 字段：`widthTwips`、`heightTwips`、`marginTopTwips`、`marginRightTwips`、`marginBottomTwips`、`marginLeftTwips`。1 pt = 20 twip。null、部分字段、未知字段、字符串/浮点/布尔、非根节点上的属性均拒绝。

- 纸张名只用于识别受支持子集：A4 为 11906×16838、Letter 为 12240×15840、A5 为 8391×11906 twip，支持长短边互换
- 每个尺寸允许名义值 ±2 twip，以涵盖实际文件的常见整数换算；保存原始整数，不吸附到预设。原始 POI `SampleDoc.docx` 的 11907×16840 就属于该子集
- 四边各 0–4320 twip（0–216 pt），正文宽高各至少 1440 twip（72 pt）；这是产品数值边界，不是完整纸张库
- 界面可选预设、横纵向，边距以 0.05 pt 精度输入。只改边距时不把源纸张的 ±2 twip 差异改成预设值
- “默认页面”移除属性。无此属性的 V1/V2 文档、旧草稿和 DOCX 编码保持原样，不自动升级。旧 V1 的 DOCX 72 pt 边距与打印 20 mm 边距之间的历史差异也不借本轮重写

## 缩小页面不会悄悄缩放对象

有显式页面时，固定表格的列宽总和加非负缩进不得超过正文宽度。带任意位置属性的自动表格（包括显式左对齐或缩进 0）沿用 9000 twip 作者默认宽度，同样严格检查；不会自动缩放已声明的几何。

仅对没有固定列宽、也没有任何位置属性的普通自动表格，新显式页面路径将作者默认宽度明确规范化为 `min(9000, 正文宽度)` twip。DOCX 表宽、默认列/单元格宽和编辑/打印声明使用同一派生值；不能把它称作保留源列宽。整数余量从第一列开始分配，模型仍保持自动，不填入固定列宽数组。纸张、方向或边距变化时，这类自动表格会随正文区重排；界面明确提示此行为。旧无页面属性分支仍用原 9000 twip 编码，撤销/重置能恢复原分支。普通 Letter/A5 自动表格因此可用，而不是因为应用自己的旧默认宽度被误拒绝。

显式页面目前只支持正文顶层表格；不能用页面正文宽度冒充嵌套单元格或列表容器的可用宽度。嵌套/列表内表格不进入本轮页面适配子集。
图片保留既有显示尺寸资源上限；显式 EMU 框须同时适合正文宽高。无显式尺寸时按既有导出算法（自然像素、最大 600×800 CSS px、不放大）确定框，并检查适配；媒体方向/动画无法证明时拒绝。新显式页面路径让编辑/打印声明采用同一自然框，不向模型补写隐式尺寸、不改原媒体。缩小页面造成不适配时整次修改拒绝，正文、草稿和撤销历史不变。

这些检查只约束已知对象尺寸和明确规范化的自动宽度。它们不是正文分页引擎，也不保证自动表格内容不会撑宽；旧兼容模式下显式左缩进 0 的表格边框仍可能向左突出其左单元格边距（缺省 108 twip，后续可设置统一物理边距，见 TABLE_CELL_MARGINS.md）。没有声称表格边框、单元格正文、整段文字或所有分页都完全落在正文区。

## 外部 DOCX 的证明边界

页面声明、实际 OPC styles/settings 关系与正文转换使用同一个有界源快照，不再次按路径读取。不根据解析器补出的默认值猜测源页面。

仅支持正文末尾唯一 `sectPr` 中明确、唯一的 `pgSz` 和四边完整 `pgMar`；尺寸、方向、命名空间、位置、数值和实际解析结果交叉核对。整个 sectPr、pgSz 或 pgMar 缺失的旧源继续按旧 A4 路径转换，但明确提示页面规范化；属性存在但必填字段残缺、显式不支持或矛盾的页面声明拒绝编辑副本。

多节/段内分节、连续分节、方向冲突、负边距、非零装订线、镜像/书籍模式、活动文档网格、多栏、RTL/竖排、首页特殊布局、页边框、打印机设置及超出纸张子集等不宣称支持。中性的单栏、关闭网格、从左到右、顶部对齐等允许；活动/默认样式链受审计，未使用的普通模板样式不应阻止导入。

没有增加页眉页脚编辑。实际附属内容继续由关系/引用审计拒绝；无附属内容时的 header/footer 距离与纸张 code 不代表可见正文几何，可明确规范化，不能因为常见的 720 twip 距离存在就误拒绝普通文档。

## 打印与验证边界

显式页面的 DOCX `sectPr`、编辑页框、不可变打印快照 CSS 和原生 PDF 参数取相同整数。原生参数使用每边边距；输出验证检查所有页面的实际 MediaBox 尺寸，并对新显式 Word 页面拒绝旋转、不同裁剪框或改变物理尺度的 UserUnit，不猜测文字页数。普通系统打印窗口仍可能通过用户选择的缩放、打印机和页眉页脚选项改变效果，需要检查预览。

独立套件由 python-docx 生成定向源，另存预设期望清单；使用独立 OOXML/python-docx 读取、完整可信模型重开、源 SHA-256、覆盖拒绝、失败无输出、篡改包拒绝，以及 LibreOffice 页面/位置探针。未改造的固定上游原件和自行生成的样本分列，不能称为用户生产文件。实际计数、证据路径、回归及未执行项目见 [REGRESSION.md](REGRESSION.md)。
