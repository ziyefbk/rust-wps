# 外部 DOCX 的有界 Roman / Swiss 字体类别保留

本轮只保留源明确声明的字体类别，沿用已有根 `fontFamilyMetadata`、草稿、DOCX fontTable 与可信重开。不重命名字体、不安装字体、不改源颜色，也不指定本机替代字体，也不按名字、粗体、PANOSE 或某个消费者的结果推测类别。`fontFamily` 字符标记仍是字面字体名，根元数据表示 `roman` / `swiss` 分类。

发布 35（2026-10-14）在发布 34 的严格根模型、writer 和可信重开能力上增加外部 DOCX 源证明。此前“通用外部导入不读取类别表”是发布 34 的历史边界；现在只有下述完整证明子集可新增类别，不能把任意 fontTable 或内嵌作者模型当作可信来源。实现前 ZIP 实验与最终产品验收分开记录。

## 支持子集

- 普通正文顶层段落与标题、直接 `w:r/w:t` 的有限 Latin 文本；不同 run 可采用不同名字，但每个有效范围的 ASCII / hAnsi 两槽必须分别有证据且得到同一个精确名字
- 真正空段必须已被现有空段字体证明保留完整 `emptyParagraphFont`，再把该名字加入本轮完整保留集；任何缺少基线证明的真空段使新类别整组回退
- `w:t` 内即使只有空格也属于文字范围，不冒充空段；不修剪、折叠空白、改写 Unicode 或用名字集合替代逐范围身份
- 源已有的无格式覆盖独立手动分页段可以保持原子身份和顺序，具体默认字体限制见下节
- 有效字体按文档 run 默认值、实际段落 basedOn 链、显式字符样式链、直接 run 属性顺序解析；显式段落样式不额外叠加默认段落样式，没有显式 `rStyle` 时不添加默认字符样式
- 同层主题引用优先于字面名字；后层字面值仅替代对应槽的继承主题。只支持唯一实际主题的普通 Latin 槽及有界语言身份；受支持的初始语言为 en / es / fr / de / it / pt / nl，可有 Latn 和普通地区子标签。未知、非 Latin、冲突脚本或活动 supplemental Latn 映射整组回退
- 文字字符限于可打印 ASCII、除 micro sign 外的可打印 Latin-1，以及已有 Windows-1252 Latin / 标点集合，包括真实原件的弯引号。不是任意 Unicode 或复杂文字支持

表格、列表 / 编号、图片、超链接与其他 run 容器、制表符、普通换行 run、文字与手动分页混合段、符号、复杂 / 东亚文字、活动 `cs/rtl` 或非默认字体 hint、替代名字、嵌入字体等不在首版范围。源的东亚 / cs 字体、字号、粗斜体和校对语言声明如果并未被本轮 Latin 文本使用，不因此单独认定正文为复杂文字。未使用的模板样式不提供新类别证据。

## 分页和默认字体的明确限制

只有一个 `w:r`、一个 `w:br type="page"`，且不含 `w:pPr` / `w:rPr` 格式覆盖或样式引用的真正独立分页段进入有界身份证明。源位置、数量和转换后的裸原子必须完全一致；不从分页段推测类别或度量，不移植旧二进制 DOC 的 split-page-break 语义。

writer 仍输出历史裸分页 XML；它继承目标 V2 的默认 Latin 字体 Arial，而不是 SampleDoc 源分页继承的 Calibri。本轮的完整保留集只包括已证明文字与实际保留的空段基线，不包括所有隐式输出字体。

fontTable 是文档级状态。如果其他已证明文字 / 空段恰好采用目标默认名字，新增类别仍可能影响该名字在分页段的替代。因此裸分页 XML 未变不表示物理分页行框已证明或渲染度量不变；原有源默认字体与版式规范化限制保持。

## 源、关系与名字唯一性

只读取原有最多 64 MiB 的同一字节快照。采用主文档的实际内部 fontTable 关系，核对原始 OPC 关系、Content Types 和唯一物理 ZIP 条目；可支持正确关系指向的其他文件名，孤立的惯用文件名没有权威性。主文档仍限既有标准位置；不从 glossary、外部链接或文件名猜测字体表。

字体表、样式、主题、设置等角色必须唯一且不同于控制部件。重复 ID / 角色、未知 TargetMode、错误 MIME、重复 Default / Override、大小写或百分号别名、外部或缺失目标使证明不可用。百分号编码须完整、有效 UTF-8，不能隐藏分隔符、控制字符或其他拒绝的目标语法；不能依赖便捷关系或内容类型 map 的 first / last 覆盖行为。

字体表必须是正确命名空间下的直接 `fonts/font/family` 路径；支持表自身的等价命名空间前缀，但 reader 实际消费的活动 WML 属性路径采用严格字面 `w:` 身份。DTD、自定义实体、重复属性、同局部名外来声明、包装 / 重复 family、未知类别和活动扩展都不可作为证据。根 `mc:Ignorable` 仅在其前缀明确声明且没有实际不支持扩展内容时作为命名空间说明接受。

每个保留名字必须在完整 ASCII 大小写折叠类内只有一个精确同名定义，且 family 是 `roman` 或 `swiss`。同值重复、冲突重复、大小写别名和只找到不同大小写的记录都不能挑 first / last。重复引用唯一记录可合并；不会做 Unicode 正规化或完整大小写折叠。

缺少 family 合法地表示 auto；显式 auto / modern / script / decorative 或缺少精确记录时，所有新类别共同回退。无关未使用记录可采用其他合法类别或较长名字；不在活动名字折叠类内的无关重复不提供证据。结构非法的字体表仍整组不可用。已知 PANOSE、charset、pitch、sig、notTrueType 可检查结构但不保留；活动非 Latin charset、altName / embedding 不可冒充完整字体身份，不读取字体程序或安装字体。

这与二进制 DOC 的“未用 FFN 索引”不同：DOCX 使用名字引用整组定义。已有 exported blank.doc 的真正空段保留 Arial 22，而字体表只有 Times New Roman/roman，所以本轮仍应整组省略类别，不能只保留 Times New Roman 来让测试通过。

## 原子提交与回退

新证明不会改变任何旧导入拒绝。先完成全部既有审计、转换、几何 / 间距 / 空段附加和模型校验，再核对完整正文、每个字体范围、空段基线和裸分页身份。允许等名字的相邻范围因其他格式而拆分 / 合并，但必须逐字相等。整个候选通过现有模型校验后，只新增根字段和一条固定提示；任何失败都不提交部分记录，也不改已有颜色、字体名、字号、标题、布局、计数或旧提示。

成功提示：

> Source-declared Roman/Swiss classifications preserved for proved Latin text and empty-paragraph fonts; other font metadata, bare-break defaults and local substitution remain unproved

不可用时仅新增一条限定提示：

> DOCX font-family metadata not preserved: [具体稳定原因]; existing imported fonts and layout are unchanged

具体原因按包身份、表结构、正文子集、字体 / 样式 / 主题身份、缺少支持分类、重复 / 别名、源模型范围绑定、资源限额或候选模型校验分类；不输出源 XML 中任意字符串。这里的 unchanged 指保留旧导入模型，不代表与源物理版式相同。

真实缺省关系、合法空表，或已证明没有文字 / 空段保留字体的正文保持完整旧响应，没有额外提示；声明了但丢失的目标不属于缺省。`audit-docx`、只读检查、通用 IR 和既有拒绝链保持，`fidelity_verified` 仍为 false。

根元数据一经纳入模型，可以在删字、改字体或清空后继续存在；草稿、撤销和可信模型重开沿用旧能力。通用 `import-docx` 必须重新完成上述源证明，不能把内嵌作者模型当成字体来源认证。可信重开仍保留合法未使用作者记录；通用导入只接收此次完整证明的保留集。

## 配额与验证边界

沿用 64 MiB 输入、4,096 ZIP 条目、128 MiB 展开和现有编辑模型配额。新证明额外限制：主 XML 16 MiB；被读取辅助 XML 累计 1 MiB；字体定义 / 保留名字各 256；样式 4,093；段落 / run 请求和最终编辑节点各 10,000；源 Unicode 字符 1,000,000；XML 深度 128、累计节点 100,000、单节点属性 64、单属性 16,384 bytes；样式链 64 层、累计遍历链接 10,000。

活动样式预检、字体辅助解析及空段解析共同受 5,000,000 次保守树访问预算限制。重复段落 / 样式 / 主题扫描提前计费，不能由缓存表面上掩盖二次增长；合法但超过新证明预算的来源仅类别回退，不截断或扩大旧拒绝。
