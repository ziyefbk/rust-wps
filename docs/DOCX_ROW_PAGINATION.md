# DOCX 表格行内不分页

> 发布 36，2026-10-14。以下为有界功能与独立证据；不代表完整 Office / WPS 版式兼容。

正文顶层、无合并、无嵌套的矩形表格新增逐行“行内不分页”设置。缺省、显式关闭和显式开启分别保存；源 DOCX 只在直接声明、活动样式与逐行文字身份共同证明后保留。它表达 DOCX 行分页意图，不实现编辑器自动分页，也不保证超过一页的行不跨页。

## 设置与严格模型

- 控件“行内不分页”提供“默认 / 开启 / 关闭”，多行不同值显示“混合”。光标作用于当前行，受支持的跨格文字选区、单元格 / 行 / 整表选区作用于实际覆盖行；跨出同一受支持表格的选区不静默缩小范围
- `tableRow.attrs.rowCantSplit` 只接受省略、布尔 `false`、布尔 `true`。“默认”删除属性；关闭仍是有意义的显式值，不能当缺省过滤
- 外部原始 JSON 的 `null`、字符串、数值、数组、对象，以及错误节点 / 标记上的同名属性均拒绝。编辑器内部 schema 缺省 null 仅在已知行属性的快照规范化中移除，不能借此放宽原始输入
- 新属性仅适用于正文顶层的非空矩形表格，沿用最多 500 行、每行最多 50 格、无合并 / 嵌套的限制。旧无属性模型保留原路径，不升级默认样式或自动添加 false
- 行分页、最小行高、单元格垂直对齐和既有表头类型分别保存。作者可以合法组合有效最小行高与 true / false；仍受已有页面与行高上限约束。自然增高的长内容不因该布尔值被拒绝、剪裁、缩小或塞入固定高度

## 编辑、粘贴与失败保护

设置使用完整候选校验和一次提交，保留其他行属性、单元格内容、选区与字符格式；可撤销 / 重做。相同值及对缺省行重置不产生新历史。过期选区、文档 / 编辑器切换、保存或打印锁定、非编辑状态和输入法组合期间不得误改其他行；失败不写入新草稿。

行属性属于原来的行，显式 false 与 true 受到同样保护：

- 行内输入、删除所有文字再输入、字符格式和普通文字粘贴保留目标行设置；新增行从缺省开始，不继承相邻行 true 或 false。增删列保留幸存行的设置
- 删除完整行、整表或清空整文档会移除对应完整对象；重新创建的行没有旧设置，撤销恢复原对象的完整属性。既有表头切换保留该行设置，不新增重复表头能力
- 无显式源行设置的普通单元格内容粘贴沿用目标行设置；真正新增行保持缺省。不能根据文字相同猜测行身份
- 带显式行分页设置的结构化行 / 单元格片段，暂不支持粘贴到现有表格；可复制普通文字，或在表格外有效的正文顶层位置粘贴完整闭合表格。完整闭合表格须经过原始 HTML、解析后结构及完整候选校验，逐行保留三态
- 除下述单段文字例外外，带显式设置的开放片段、不支持的嵌套目标，以及无法证明行身份的合并、修复、移动、结构重建或跨边界删除，均不得静默丢弃 / 复制 / 移动设置。拒绝保持原文档、历史和草稿
- 唯一的复制文字上下文例外：`openStart = openEnd = 4`、单个仅含行内内容的普通段落 / 标题，且目标为同一单元格内的文字选区时，可只粘贴该文字并保留目标行设置，不移植源行设置。结构化 `CellSelection` 或开放行粘贴仍拒绝；不能推广为任意开放表格片段支持
- 自有 HTML 只在有效表格行 `tr` 接受精确 `data-row-cant-split="true"` / `"false"`。错误节点和值在 schema 丢弃证据前检查；外部 CSS、MSO、表格 / 单元格样式不会被猜测为行元数据

无浏览器插件与 DOM 运输测试覆盖见验收记录；这些不是实际系统剪贴板、输入法或键盘验收。

## 外部 DOCX 源证明与整组回退

审计与转换共用有界源快照，主文档仍限定为 canonical `/word/document.xml`，styles 则按实际 OPC 关系定位（支持非标准 styles 部件名）；没有新增任意重定位主文档支持，也不依赖转换器的宽松布尔默认值。

1. 只证明直接 `document/body/tbl/tr/trPr/cantSplit`。属性缺省表示 true；精确 `1 / true / on` 表示 true，`0 / false / off` 表示 false。要求受支持命名空间、canonical `w:` 路径、唯一直接声明、正确命名空间属性、空叶结构和无非空文字。重复、包装、未知属性 / 值或属性同名碰撞不进入子集。正确命名空间的其他前缀也可能是合法 OOXML，但不在此 canonical-w 证明范围，不应称其为损坏 XML
2. 显式表格样式或实际唯一默认样式及完整 basedOn 链须能证明。活动链中的基本或条件 cantSplit 声明，包括 false 和看似被直接值覆盖的声明，本轮均不展开继承。未使用样式单独不引入新的行分页变化
3. 源表格须为直接正文矩形结构，逐行逐格的完整普通 / 标题段落、空段、文字、软换行 / 制表符及已有支持的内联内容与 IR、最终模型顺序绑定。列表、图片、字段、硬分页、复杂包装或不能证明的行身份不因布尔属性被理解而放行
4. 既有直接表头声明还要核对原始路径、布尔值与 IR 表头类型；沿用已有单元格类型表示。本轮没有新增表头编辑或继承支持
5. 所有候选表格组成一个文档级原子保留组：全部证明通过才一起附加直接存在的行设置；任一候选不能证明则整个文档不新增行设置，只保留完整旧模型并追加一条分类回退提示。其他独立证明的旧属性不撤销，不产生部分保留与回退并存的成功报告
6. 无候选保持旧响应和模型，不凭有效“允许拆行”推造 false。旧导入硬拒绝及错误优先级保持；成功的非阻断 `audit-docx` 报告与 `import-docx` 拒绝是不同命令合同，不能把导入错误相同误写为所有审计响应完全相同

回退原因区分包 / 活动样式身份、源结构 / 继承、直接声明、源与转换身份和证明资源上限。源高度 / 垂直对齐与 cantSplit 组合的既有拒绝仍保留，不能因为作者模型可组合就扩大外部源几何范围；隐藏文字、修订、附属内容、关系、合并、方向和页面等旧保护不放宽。

真正样本包含的书签配对与 Nicolaas 的拼写 `proofErr` 配对仅按受审计的空叶、属性、顺序和范围规则计入零可见文字证明。这不保存书签导航或校对状态，不允许忽略任意未知标记；既有锚点 / 超链接限制不变。

源快照沿用 64 MiB、ZIP 4096 项 / 128 MiB 展开、XML 100000 节点 / 深度 128、样式链深度 64，并对样式解析和行证明分别采用累计工作预算。模型仍限制 10000 节点、深度 32、2 MiB 文字及 32 MiB 序列化草稿；没有提升原有资源上限。内部测试覆盖 64 / 65 样式链，但 CLI 端既有段落缩进链上限 20 先行拦截 21 及以上；实际源正对照只证明链 20 与累计工作恰好 2,000,000。紧凑工作 2,000,001 被旧表格几何保护先行拒绝，不能宣称 CLI 支持链 64 或已到达新超工作预算分支。500 行、50 格、文字恰好 2 MiB 的实际源正对照及各自 +1 旧拒绝已核对。

## DOCX 写出、可信重开与原文件

存在 true 写出 `<w:cantSplit w:val="1"/>`，存在 false 写出 `<w:cantSplit w:val="0"/>`；省略不新建行属性块或声明。无新属性的旧模型要求整包历史字节保持，既有表头 / 最小行高输出顺序与其他部件不应被无关改写。

自有文件使用 `read-docx-model` 完整可信重开：严格模型、规范重新编码、模型散列、完整部件集合和部件完整性共同核对。普通 `import-docx` 是外部源审计，不能代替可信重开。作者的合法“最小行高 + 行分页”文件可以导出 / 可信重开；去除可信元数据后按外部源导入仍可能命中原垂直布局拒绝，二者不是矛盾。

源文件始终保留，导出另存新文件，不覆盖已有文件；无效输入、超限、失败写出、篡改重开与失败编辑都应保持原件、已有输出及原有草稿。原件散列、不覆盖与完整性拒绝分别记录在独立源验证和最终消费者证据中。

## 浏览器打印默认值的有意差异

连续编辑区不分页。打印快照保留行数据属性，但 CSS 仅为浏览器提示：显式 true 使用 `break-inside: avoid`，显式 false 使用 `auto`；缺省行继续沿用历史 `#print-document tr { break-inside: avoid; }`，不全局改变旧文档打印行为。

因此，没有继承声明时，源 OOXML 缺省的“允许拆行”与历史浏览器缺省的 avoid 提示并不等价。保留缺省不会偷偷改为 false 来制造一致性；不同消费者可以产生不同分页。不可变打印快照与后续编辑 / 重置隔离，不通过伪分页节点、手工偏移、固定高度或隐藏溢出来补偿。

## 真正原件与诊断证据

未改造语义正对照为 Apache POI [Bug60337.docx](https://github.com/apache/poi/blob/ae62bb5116b9aee19ebd5834e3a82066132c9f7f/test-data/document/Bug60337.docx)，revision `ae62bb5116b9aee19ebd5834e3a82066132c9f7f`，13463 bytes，Git blob `06d0339fc5f854d90fe6721d991c512c815da4c5`，SHA-256 `87f983bdd93b3b5b8469104a5b09ccff41e0f5c144060e13fd4db07bfd2e39da`。这是公共上游回归夹具，不是用户生产文档；不作新的再分发许可结论。

原件为 3×5 表格，第一行已有表头表示，第三行 Task II / 20 / 5 / 5 / 15 有直接 cantSplit，其他两行没有；没有最小高度 / 垂直对齐。活动 TableGrid → TableNormal 无继承 cantSplit。必须完整核对 15 格段落顺序，而不是仅查到一个 XML 标签。源自动列宽仍按旧路径规范化，产品仍按旧路径添加蓝色表头底色；保留行分页不能关闭这些损失。

短原件、旧输出及 flag-only 诊断输出都是一页：原件提供真实源语义证据，不提供可见分页改善。分页因果证据另来自明确标记的作者控制：36 个前导段落加第三行每格 12 个段落时，true 将目标行留到第二页，false / 缺省跨第一页与第二页；每格扩展到 60 段时，true 仍可跨第二、三页，false / 缺省跨第一至第三页。不能说开启后长行绝不跨页，也不能只靠总页数判定成功。

此前诊断共 23 份隔离 PDF / 53 页；最初 42 个前导段落的边界没有产生 flag 效果，失败 / 无效果证据保留。诊断中仅改旧输出 XML 的 ZIP 留有陈旧内嵌完整性，可信重开应拒绝；它们只能解释机制或提供独立消费参考，绝不是新产品有效输出。
