# 有界十进制列表几何

本轮针对一份真实、未改造的 LibreOffice DOCX 编号回归文件，新增可证明的顶层十进制列表缩进和编号字体保留。不是一般 Word 编号、命名样式、任意多级列表或全页保真支持；DOC / PDF 的既有路径不变。

## 支持模型

- 顶层 `orderedList` 可带完整 `markerFont: {fontFamily, fontSize}`。`fontSize` 为整数半磅，范围 2–3276；字体为一个有效字面名称，最多 31 个 UTF-16 单元。编号独立使用普通、非粗体、非斜体黑色 Latin 字体
- 每个 `listItem` 必须只有一个 `paragraph`，该段带完整 `listGeometry: {leftTwips, rightTwips, hangingTwips}`。三个值为整数 twip，范围 0–31680；`hangingTwips <= leftTwips`，左右缩进之和严格小于显式页面正文宽度。显式零与省略不同
- 必须存在受支持的单节 `pageGeometry`；列表、项和段落容器精确校验，不接受表格/嵌套列表/标题/图片/分页符或多段项。正文只允许文字和普通换行，不允许制表符、CR、自定义编号类型、非左对齐或普通段落缩进字段与列表几何混用
- 模型中新增空项可由受控 Enter 产生，它使用现有 `standard-v2` 空正文语义。模型不会把源空段基线字体暗中改成另一种保留承诺
- 没有新属性的历史列表继续使用原有模型、验证和 writer 路线，不增加 `null` 字段或改变其包字节

上述检查的是声明的段落行框，不是任意编号字形/长词的占用宽度。零悬挂、很长的编号或大字号可能触发消费者的后续默认制表位；独立检查包含起始 99 的零/一 twip 悬挂，不能据此承诺一般字形不会溢出。

## 外部源的更窄证明

新源审计读取同一有界 DOCX 快照中真实 OPC 关系指向的部件，不依赖固定 styles/numbering/theme 文件名。编号、样式、主题/设置关系须唯一、内部且命名空间有效；模糊、外部、缺失或重复身份不能变成可编辑证明。

初始源子集为整个正文都能按直接段落顺序证明的文档：所有活动列表均为 level 0、`decimal`、精确 `%1.`、左对齐编号、普通 tab 后缀；每个编号实例只有一段连续运行，不能穿过正文段落后继续同一实例。完整正文块数量、类型、顺序、文字、列表边界、项数和起始编号都须与转换后的模型一致。只按列表文字或总数匹配不够，重复文字也不能绕过结构绑定。

每个相关缩进声明层必须是完整、非负的物理 left/right/hanging 三元组；不能拼接部分声明猜测 cascade，负值即使被后层覆盖也不放行。活动 level 0 必须与一个无歧义的段落样式关联，该样式解析到同一编号实例；派生样式可继承该关联。原件的 Style2 → Style1 属于此子集，任意祖先名字出现在链上不构成充分证据。

编号字体从经过审计的默认/段落样式和有限 Latin 主题解析，不能拿第一个正文 run 的字体当编号字体。编号层 `rPr`、段落标记覆盖、特殊颜色/效果、未证明的字形或强调保持拒绝。主题变成固定字体名，未安装的字体仍可能由本机替代。

源设置仅允许缺省或显式 720 twip 默认制表位及已校准的兼容设置；非标准制表位、编号制表兼容开关、自定义 tabs、RTL/mirror、逻辑/字符单位、链接编号样式、完整或简单编号覆盖/重启、图片编号、Roman/字母/自定义 pattern 均不进入新模式。未使用的模板层级不代表其受支持，也不会阻止独立、无歧义的活动 level 0。

源空列表项、纯空白、空 run/空格式 run 及显式换行目前不进入此保留子集。独立空源探针发现源 Calibri 11 与导入后空正文 Arial 11 导致 0.05 pt / 1,659 像素差，因而保守拒绝；不调整像素阈值掩盖。普通显式换行+文字的一个探针相等，但尚不足以扩大源基线语义。新建/编辑过程中受控 Enter 的空项属于已明确的作者模型语义，独立参考使用其 Arial 11 默认值。

失败的新增证明不会删除旧保护：此前允许的普通列表仍带原有编号外观/缩进规范化警告；此前因非零、复杂或模糊缩进而拒绝的列表，只有完整通过新证明才扩大到编辑副本。没有修改 vendor 的通用列表缩进优先级。

## 编辑、草稿与导出

- 项内文字、字符字体/字号/标记、段落间距可继续编辑；受控 Enter 在当前项内拆分，显式继承该项的三元组和段落属性，支持一次撤销/重做
- 暂无列表几何数值控件。不能删除整个受保留列表/列表项、提升/嵌套、合并、移动或切换列表；这些结构变换在应用候选事务中原子拒绝。项内文字删除仍可用
- 页面缩小/清除、粘贴、草稿恢复和打印快照都走精确模型/容器验证。非法候选不改变文档或历史；普通无新属性的开放列表粘贴保持旧路径
- 编辑器与打印共享专用 counter / 字体 / twip frame CSS；它是有界预览，不等于浏览器自动分页、Word 默认制表位或原生打印的物理验收
- DOCX 导出仍是真实 `numPr` / numbering，没有把 `1.` 写成正文。每项写显式 `w:ind`，专用编号定义写独立字体，旧两个 abstract definitions 与无新属性包字节保持
- 本应用导出文件通过完整哈希、部件集合、重编码内容绑定后用 `read-docx-model` 可信重开。强制走外部 `import-docx` 的输出文件仍可能因专用 marker `rPr`、无源 pStyle 关联和 start override 而拒绝；不为此扩大外部源解析子集
- 原件不写回；已有另存目标继续拒绝覆盖
