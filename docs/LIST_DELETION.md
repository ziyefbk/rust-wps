# 保留编号列表的有界删除

在已有 [十进制列表几何](LIST_GEOMETRY.md) 模型上，新增边界明确的整项、整列表和整文档删除。这里只扩展前端选区操作，不扩大 DOCX 源审计、模型、Rust writer 或一般列表结构变换的支持范围。

## 操作与编号语义

编辑器注册的普通 `Delete` / `Backspace` 支持：

- 整个受保留 `orderedList` 的节点选区：删除该列表，其他块原样保留
- 受保留列表中一个 `listItem` 的节点选区：删除该项；首项、中间项、末项都相同。唯一项删除时同时删除其列表容器
- 同一列表内，从某项**文字开头**选到后面某项的**文字开头**：删除完整跨过的项，保留终点所在项。正向和反向选区相同
- 从某项文字开头选到该列表**紧邻的下一正文段落文字开头**：删除该项及其后的列表项；从首项开始则删除整列表。下一正文段落完整保留，不把其文字拼入列表项
- 整文档 `AllSelection`：清空文档内容，保留根节点的 `styleProfile` / `pageGeometry` 等属性

如果删除后文档没有其他块，建立一个没有列表几何或继承字符格式的默认空正文段落。没有插入伪空格、文字编号或隐藏编号残留。

**剩余列表的 `start` 不变，编号从原 `start` 连续重新计算。** 例如原编号 7、8、9，删除首项后原第二、三项显示 7、8；删除中间项后原第一、三项显示 7、8；删除末项后为 7、8。不是保留被删除项留下的编号空洞，也不将源起始值偷偷重置为 1。保留项的完整段落属性、正文、字符标记、左右/悬挂几何及列表独立编号字体逐项保持。

只选中一个项的全部文字，仍然只清空该项文字并保留空项与编号。要删除末项，可选到紧邻下一正文段落的开头；没有这种终点时，可使用准确的项节点选区或整文档选区。没有新增节点选区按钮或专用数值控件。

## 保守边界

- 部分跨项选区、跨列表文字选区、任意混合块删除、合并不同格式的部分段落、移动、提升、嵌套和切换列表仍拒绝。多项文字末尾的选区不等同于完整项边界，不猜测用户意图
- 光标无选区时，项首 Backspace / 项末 Delete 的合并行为不放行；普通项内文字删除维持旧路径
- 应用拥有的候选函数与注册按键处理是新入口；任意程序直接调用原始 `deleteSelection` / `tr.delete` 不能绕过保护。触摸、IME、剪切、浏览器 `beforeinput` 或其他上游命令没有因此获得新的结构删除保证
- 非保留普通列表不进入新路径；剪贴板、页面缩小、非法元数据和源导入的既有拒绝边界不扩大
- 只读或应用锁定时不派发删除事务。错误候选不修改文档、草稿或历史

## 事务、历史与草稿

候选基于当前不可变文档和选区，在独立临时事务中删除完整节点边界，不改写 Tiptap 链式命令共享的事务。私有 WeakMap 将授权绑定到同一事务的源文档与最终文档对象；事后追加替换、重排、删除/重插或伪造公开 meta 不能取得授权。

同一个 ProseMirror 不可变节点对象可以出现在多个位置，因此同一列表的证明比较实际列表边界位置，不靠节点对象身份猜测。连续性保护另检查项的结束边界，防止从末项跨到外部段落的原始删除留下列表壳却丢掉外部段落格式；合法项内文字和段落属性事务仍可通过。

应用按键删除前后隔离历史分组。立即执行“输入 → 删除项 → 输入”后，可分别一次撤销每步，删除撤销精确恢复删除前文档和选区；重做恢复对应结果。草稿使用现有 JSON 模型运输/恢复，没有新增版本。默认自动补尾段插件的全链行为已在无浏览器状态中测试；不等同真实磁盘草稿或 WebView2 键盘验收。
