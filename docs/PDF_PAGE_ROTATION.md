# PDF 当前页旋转另存

第一版页面操作只提供“当前页顺时针旋转 90°，另存副本”。源 PDF 保持打开，源路径从不用于写入，也不自动切换为输出文件。页面必须已经完成渲染；一次失败的翻页不能把旧画布当作新页来保存。

这是有限的 `/Rotate` 页面方向变更，不是正文编辑、OCR、标注、裁剪或通用 PDF 重写。输出保留完整源字节前缀，再追加一个选中页面对象和必要的交叉引用 / trailer 更新。首次实现拒绝已有历史修订，因此保存后的副本可以重新打开预览，但不能再次用本功能旋转另存；原件仍可分别另存其他当前页的副本。

## 明确支持范围

- 同一经既有会话身份验证的 64 MiB 以内源缓冲区；PDF 1.0–1.7 文件头必须位于字节零
- 单个传统 xref 表、从对象零开始的单一连续 subsection、固定宽度记录；零号空闲、其余对象均为有效 generation 0；`Size`、对象集合、偏移和实际对象头必须相同
- 最多 20,000 个对象、1,000 页、4,096 个树节点、64 层树 / 词法嵌套与 500,000 个合计词法 token
- trailer 只允许 `Size`、`Root`、可选 `Info` / `ID`；Catalog 只允许 `Type` / `Pages`。可选 Info 必须指向实际字典；ID 若存在，须为两个 16 字节十六进制字符串
- Page / Pages 字典只接受明确类型、父子引用、计数、Contents 和受支持继承属性：Resources、MediaBox、CropBox、Rotate。严格原始语法识别只允许未转义名称、32 位整数、generation-zero 引用与简单数组，不接受重名键、实数、字符串、嵌套字典、额外 token 或未知属性
- 显式遍历验证每一个 Count、Parent、孩子唯一性、顺序与无环性；不使用宽容的 `get_pages()` 枚举。有效 Resources 必须指向字典；Contents 只能缺省、为单个 stream 引用或有限 stream 引用数组
- 有效 MediaBox 必须是四整数数组，坐标在 ±1,000,000 内，正宽高各不超过 14,400 pt。CropBox 缺省取 MediaBox，显式或继承裁剪框须包含于媒体框。Rotate 必须是可精确表示的 32 位整数、90 的倍数，安全归一化至 0/90/180/270

已有修订、xref stream / hybrid / object stream、加密（含空密码自动解密）、线性化、签名、表单、注释、动作、标记结构、其他页面框、UserUnit、未证明属性与歧义语法均拒绝。有效页面资源可包含共享字体、图片和 Form XObject；资源与内容字节完全不重写，但不声称完整审计其绘制语义。

## 物理对象保护

仅核对 xref 中的对象头不能证明该位置不是藏在另一个 stream / 字符串中的伪对象。本轮增加有界的物理 framing 检查：按实际偏移排序，逐段只接受一个完整直接值，必要时按直接或单跳原始整数字段 Length 精确跳过 stream，再要求准确的 endstream / endobj 和剩余空白 / 已结束注释。

该检查仅证明字节边界，不创建任意 PDF 对象模型、不修复解析、不搜索替代 endstream、不解压内容。所有 framed 字典使用解码后的唯一键名，防止 Length 与转义别名形成歧义；间接 Length 必须来自单独 framing 的原始整数对象，不允许引用链或循环。所有间接引用必须实际存在。敏感名称也在非 stream 数据中保守拒绝，包含孤立签名 / 动作字典；stream 内容里的同名字节不会被误当作字典。

原始 trailer、Catalog 和所有页面树字典还与 lopdf 实际解析值逐项相等。lopdf 跳过对象、修复 xref 或忽略重复键不构成放行依据。

## 唯一修改与输出验证

使用 pdf-extract 现有公开类型重导出，不新增依赖、不改 vendor。`IncrementalDocument` 接收完全一致的源缓冲区和已审计模型，仅加入当前叶 Page 对象的显式有效 Rotate。继承祖先和其他页面不变。

必要的 trailer 变化为新的 xref、Prev、Size 以及文件 ID 的第二项；原第一项保留，第二项由源 SHA-256、页面对象身份和目标方向确定性派生。没有原 ID 时，第一项也由源摘要派生。输出验证在写入最终路径前完成：

- 完整源前缀逐字节一致，输出仍不超过 64 MiB；有界 writer 在超限追加前失败
- 重新打开后对象集合相同，仅选中页的活动偏移改变；所有其他对象与 stream 内容相等
- 追加段只包含选中页对象及必要的 xref / trailer；原始新页面字典只改变 Rotate，ID / Prev / Size 等 bookkeeping 与预期一致
- 再次通过显式页面树遍历核对页面次序、几何、资源及内容引用，只允许选中页的有效方向改变

## 独立图像验收的准确含义

原始目标是“旋转页像素等于源图像的精确 90°转置”。真实论文的三个页面在 Poppler 72 DPI 下没有满足这个条件，原始失败图像、差异计数和报告全部保留；不能称为源光栅的逐像素旋转。

经独立审查，采用明确区分的验收条件：39 个未选择页面的源 / 输出光栅完全相同；三个选择页面分别与 pypdf 独立生成的同方向参考 PDF 在 Poppler Splash（pdftoppm，关闭文字 / 矢量抗锯齿）和 Cairo（pdftocairo，默认设置）下的光栅完全相同。两个 Poppler 路径均独立于本应用的 writer，但不是两套无关的 PDF 引擎；参考文件是受控派生文件，不冒充未改造原件。

另外用 MuPDF 在不重写文件的条件下对输出施加反向视口旋转：关闭抗锯齿时三页与源完全相同；默认抗锯齿时第 7 页仍有 22 个低强度像素差异。这支持方向相关光栅化差异的解释，但没有证明具体根因。关闭 FreeType 的试验产生字体错误与空白图像，明确废弃，绝不据其像素相等声称通过。

pypdf 的逐页正文保持相同。Poppler 的所选页文本输出有顺序 / 断词拼接差异，第 7 页出现 sus- / pend 变为 suspend；同一工具对独立旋转参考与应用输出的正文完全相同。原始与解码后的 stream、其他对象和页面次序仍通过独立逐对象核对。图像与文本差异记录分别保留，不用空白归一化或阈值容差隐藏。

## 桌面保存事务

前端捕获成功渲染的文档、精确字符串 session token、当前页号、PDF.js page.ref、page.rotate 与总页数。另存前再次取得页面元数据，必须与画布来源一致；后端与原始页面树再交叉验证。翻页、缩放的重叠渲染由独立 attempt 身份隔离。

隔离 worker 只接收源路径 / 身份、页面选择及父进程创建的临时目录，不接收最终文件路径；只创建固定名称的候选文件。父进程独立读取候选、核对长度 / SHA 和原始前缀身份，将字节写入输出同目录的临时文件并同步，最后在短会话锁内再次检查身份并执行 `persist_noclobber`。解析、读取、哈希和同步不持有会话锁。

取消对话框不启动 worker、不创建候选或最终文件。旧会话、错误响应、非法候选、失败写入和已有目标均不发布；保存操作自身不切换当前会话。已有文件、源文件、硬链接 / 符号链接目标以及最后一刻出现的目标均不能覆盖。临时目录在作用域退出时清理。

此保证绑定 worker 已验证的源快照，不锁定外部文件：若另一程序在该验证后修改源路径，输出仍表示之前显示的源字节；新的源读取 / 保存请求会拒绝身份不匹配。它不是文件系统原子快照、历史变更追踪、对抗恶意目录置换的沙箱或崩溃恢复机制。

已有 operation 暂停保护会阻止通常的保存期间关闭。此次额外覆盖“关闭已开始等待其他检查，随后旋转保存才开始”的异步竞态，在同一原生 close handler 的 destroy 之前同步复查，不添加竞争的关闭监听器。

## 命令行入口

```sh
cargo run --locked -- rotate-pdf input.pdf new-copy.pdf 1
```

页号从 1 开始，输出必须是尚不存在的 `.pdf` 路径；返回 JSON 中的 rotation 是保存后的有效方向。CLI 使用同一核心审计 / 追加 / 候选验证，另做不覆盖发布；它没有桌面的会话与画布上下文。

## 验证方式与环境边界

核心 unit tests 使用实际生产模块，覆盖原始语法 / xref / stream framing、继承 / 树、身份、预算和文件不覆盖。独立 transport 直接包含生产 worker / session / rotation_session，真实启动子进程；确定性发布竞态测试使用明确标注的运输替身。

`scripts/check-pdf-rotation.py` 使用固定 manifest 中未改造的 Mozilla tracemonkey.pdf 原件，对第一页、中间页和末页进行独立 pypdf 对象 / 原始与解码 stream / 引用 / xref / trailer 核对。页面图像通过每页新启动的 Poppler 进程比较，渲染配置、失败证据与精确像素结果单独记录，不用结构相同替代像素证据。

前端测试执行实际 main.ts / authoring.ts 函数，使用 DOM / IPC 替身验证页面身份、取消、错误、迟到结果、重复点击、失败翻页、重叠渲染及关闭竞态。它们不是浏览器或原生验收。

当前 Chromium EPERM、云端对本机服务隔离、Linux GLib/WebKit 缺失和离线 Windows 限制仍在；没有重试已拒绝路径。实际系统对话框、WebView2、Windows Job、原生 IPC / 窗口关闭与屏幕页面验收仍需在可用桌面环境补齐。本轮执行计数、精确证据身份及渲染限制见 [REGRESSION.md](REGRESSION.md)。
