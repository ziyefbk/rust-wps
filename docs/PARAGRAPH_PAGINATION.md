# 有界段落分页属性

正文顶层段落与标题可保存三项独立属性：与下段同页（`keepNext`）、段中不分页（`keepLines`）、段前分页（`pageBreakBefore`）。这是一组 DOCX 语义与打印 CSS 提示，不是 Word/WPS 自动分页引擎，编辑器仍为连续正文。

## 模型、编辑与输出

- 每项是可选的严格布尔值：缺省、显式开启、显式关闭分别保存；不能用 `false` 当作缺省，`null`、字符串和数字不是保存格式
- 缺少属性的历史作者模型沿用旧缺省和原 DOCX 字节；包括应用标题原有的与下段同页缺省。导入的标题显式 `keepNext=false` 使用直接 XML 与 CSS 覆盖它
- DOCX 在对应段落的 `w:pPr` 写入显式 `w:val="1"` 或 `w:val="0"`。`pageBreakBefore` 不转换成独立手动分页节点，不改变段落归属
- 工具栏三项各有“默认 / 开启 / 关闭”，跨段混合值单独显示。只适用于正文顶层段落和标题；选中列表、图片、表格或单元格的混合范围整次拒绝
- 支持字符编辑、段落 / 标题转换、明确的候选事务、撤销重做与草稿。Enter 保留前段分页属性；后段复制两项 keep 值（含显式关闭），不复制段前分页；标题结尾的后段为正文。相邻同类正文 / 标题可在 Backspace / Delete 边界合并，但其他段落属性和块标记须完全相同、三个有效分页值相同且后段没有段前分页；逐字段优先保留前段显式值，否则保留后段显式值，字符标记完整拼接。涉及空行基线字体、部分跨段删除、不同属性或移入列表 / 单元格的未证明变换仍拒绝
- 从单个段落 / 标题截取的开放行内富文本可粘贴到一个顶层段落 / 标题内，保留文字、字符标记和软换行，目的段落属性不变（真正空行的基线字体仍在首次插入内容时结束）；来源分页元数据畸形、跨段目标、列表 / 单元格目标及多段开放切片仍拒绝。完整闭合段落复制保留自身属性
- 打印快照表达 `break-after:avoid/auto`、`break-inside:avoid/auto` 与 `break-before:page/auto`。连续编辑器显示提示，不伪装页面

## 外部 DOCX 的有界证明

读取同一源字节快照中 OPC 实际选择的样式部件。逐字段按以下优先级解析，不做 toggle 异或：

1. `docDefaults/pPrDefault/pPr`
2. 活动段落样式的 `basedOn` 链，从根至叶
3. 正文段落的直接 `pPr`

没有 `pStyle` 才选择唯一已证明的默认段落样式；显式样式不叠加无关的默认样式。缺失继承，空元素为真；只接受 `1/true/on` 与 `0/false/off`。从未声明的字段为假。导入的受支持段落将三个有效值显式保存，命名样式关联被固定值替代并给出提示。

检查命名空间与直接路径、重复属性 / 声明 / 活动样式标识、实际关系目标、样式类型、缺失 / 循环 / 超过 20 层的活动继承链和总解析工作量。未使用样式模板的分页属性不会单独成为拒绝理由；活动身份或声明不明确时保持只读。此前可按缺省规范化的缺失活动样式 / 缺失 basedOn 来源现在也拒绝，因为不能据此证明分页值为假；这项新拒绝在保留的 Rust 源回归夹具中明确验证；本轮另跑的 1,520 条历史响应目录内没有新增导入拒绝。独立源正文顺序、类型、完整文字和有效值必须与解析器 IR 一致，再与编辑模型核对，不能把相同文字或段落数量当作对应关系证明。

列表、表格、图片与手动分页 / 分栏拆开的源段落不进入新增承诺，保留既有规范化路径并明确提示；不向这些段落部分写入分页属性。原有图片 / 表格 / 列表审计与拒绝条件仍单独执行。分页属性不会解除它们的其他阻断。活动属性畸形或跨层绑定不明不能仅警告后继续。

## 真实来源与独立验收

本轮使用未改造 Apache POI 公开回归文件 `Styles.docx` 与 `NoHeadFoot.docx`。前者三个标题、后者一个标题的活动源样式含 `keepLines=true`；旧导出丢失此声明。两份原件中的短标题此前未出现可见重新分页，不能将语义丢失说成原件页数回归。独立边界控制另外证明：旧导出会拆开五行段落、使标题式锚点与下段分居两页、或丢失段前分页。

独立 checker 从源 OOXML 解析期望、用 python-docx/OOXML 构造参考，不能用应用 writer 自证。LibreOffice 每个转换使用独立新 profile；完整逐页文字、坐标与图像比较。两份真实原件与原始继承控制的文字 / 坐标精确相等，但已有主题阴影颜色舍入差异仍使源 / 输出像素检查失败（`365F91` → `376092`）；没有降低像素阈值。两原件另由旧 / 新输出精确相等证明不是新增颜色退化；独立黑色继承派生控制与其他边界控制保持完整像素门禁。作者无属性整包金样、完整可信重开、篡改拒绝、目标不覆盖和原件身份均单独检查。具体最终计数、冻结身份、命令和失败证据见 [REGRESSION.md](REGRESSION.md)。

## 限制

keep 属性为分页约束，过长内容仍可能被消费者拆开；段前分页可使 keepNext 链中断。未实现一般自动分页、命名样式动态联动、表格 / 列表 / 图片分页编辑、任意跨块合并或页眉页脚。真实浏览器 / WebView2 键盘、输入法、系统剪贴板与原生打印仍未验收；LibreOffice 和 Poppler 的结果不代表 Microsoft Word/WPS 或完整 Office 版式保真。
