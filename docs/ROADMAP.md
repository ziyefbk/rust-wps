# 开发目标与阶段验收

目标：Rust 核心的简洁办公工具，以本地离线使用为基础，先文字与 PDF，再电子表格，再演示文稿。

本轮扩展段前/段后间距与倍数行距的编辑、草稿和 DOCX 往返，修复部分样式覆盖及列表/空段间距丢失；独立消费者验证与未执行的浏览器/原生边界见 [PARAGRAPH_SPACING.md](PARAGRAPH_SPACING.md)。随后扩展简单矩形表格的有限固定列宽及整体对齐/左缩进，范围见 [TABLE_WIDTHS.md](TABLE_WIDTHS.md) 和 [TABLE_POSITION.md](TABLE_POSITION.md)；仍先完成文字/PDF 阶段。

## 当前能力审计

当前已经证明“Rust 文档核心 + 本地桌面界面”可以形成可运行的轻量办公原型，尚未证明完整 WPS/Office 兼容。下面区分读取与可编辑副本，不以提取成功代替布局或编辑兼容。各阶段原有未完成项继续有效。

| 格式 | 当前可用能力 | 主要缺口 |
| --- | --- | --- |
| DOC | 有界只读检查；受限正文转换为 DOCX 编辑副本，原件保留 | 复杂附属内容与完整视觉恢复；不回写 DOC |
| DOCX | 基础富文本（含显式字体名、半点字号、RGB 颜色、删除线、上/下标）、版本化默认样式、表格、图片、链接、段落对齐/间距/倍数行距、手动分页；审计导入、草稿、导出及校验重开 | 实际字体回退、动态主题及复杂样式、页眉页脚/域/公式/浮动对象、排版保真和真实输入法/剪贴板验收 |
| PDF | 本地页面渲染、缩放、密码、正文搜索；Word/PPT 近似 PDF 导出 | PDF 正文编辑、注释/页面操作、复杂中文字体与系统打印完整验收 |
| XLS | BIFF8 稀疏只读网格、类型/格式/日期系统、公式缓存身份 | 公式表达式恢复及编辑副本转换、其他 BIFF 版本 |
| XLSX | 稀疏编辑、数字格式、工作表操作、复制粘贴、排序、查找、有限公式与自动计算、草稿及另存验证 | 筛选、字体/边框等样式、完整公式依赖和重算、复杂对象兼容 |
| PPT | 旧二进制正文/备注/母版文字只读检查 | 完整对象和版式预览、转换编辑 |
| PPTX | 基础审计导入；文本框/PNG/JPEG、备注、隐藏、页操作、画布移动/键盘微调/尺寸、历史/草稿、播放及近似 PDF | 基本形状、图片与文字混合层次、完整模板样式继承、复杂图表/动画/媒体 |

当前桌面证据主要来自 Windows Debug 构建和原生 WebView2 冒烟；尚未完成安装包、发布性能基准、跨平台及广泛真实 Office 视觉对照。worker 有截止和内存限制，不等于文件系统沙箱或完整资源隔离。

此前独立 python-docx 发现的 SampleDoc DOC 手动分页丢失现已在解析层修复，配对输出恢复 1 个显式分页。正文手动分页与分节边界分开处理；分节布局、复杂排版及更多真实语料仍待完成。复现命令和最新验证边界见 [REGRESSION.md](REGRESSION.md)。

接下来按原阶段缺口推进：补齐文字/PDF 真实语料与原生交互证据，扩展 Excel 筛选/样式/重算，再完善 PPT 基本形状和对象层次。已完成的画布手柄只解决一项编辑能力，不替代上述阶段验收。


PPTX 新建模型 v1 已有 Rust/CLI 导出基础：按页组织文本框、坐标、字号和粗斜体/RGB，保留换行及空白页，输出后逐项重读验证并不覆盖发布；独立 python-pptx 对照通过。模型嵌入/验证重开及桌面文本框编辑器已接入；演示草稿自动保存/恢复已接入；共用撤销/重做历史已接入，支持页及文本框操作、草稿和保存状态；基础 PNG/JPEG 图片插入、位置/尺寸、替代文字、删除及草稿/历史已接入；基础导入可转换满足预算的直接定位 PNG/JPEG，更广的外部对象和完整内容类型仍待实现。

PPTX 已新增 Rust/CLI 单文字节点替换与不覆盖另存，并接入桌面查找/替换、原生另存对话框和隔离 worker：保留原件和未修改部件，拒绝签名/宏包，独立 python-pptx 重读文字样式及图片通过。成功后切换至保存副本并保留所选页；取消/失败保留原视图。完整演示编辑模型仍待实现。

PPTX 只读检查已接入桌面隔离 worker、文件选择器和幻灯片内容导航：页序、尺寸、逐页文字、隐藏状态及嵌套形状边界；支持有限文字样式和 PNG/JPEG 图片的近似画布预览。独立 python-pptx 和真实 worker 对照通过。外部文件尚不能完整转换为可编辑模型，母版、组合变换和复杂图形等兼容边界见 [PRESENTATIONS.md](PRESENTATIONS.md)。

## 决策原则

优先保证源文件安全与内容可解释；分离提取、预览、编辑、导出能力。
解析后端可替换，避免把单一第三方库的中间模型固化为产品模型。
