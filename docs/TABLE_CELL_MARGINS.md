# 简单表格的水平单元格边距

支持简单正文顶层矩形表格的统一左、右单元格边距。两边可不同，但整张表所有单元格使用同一对数值。当前表格控件、撤销/重做、草稿、DOCX 导出与可信重开保留设置；编辑和不可变打印副本声明相同的水平内边距。无合并、嵌套、浮动、百分比或逐格不同边距编辑。

## 模型与历史契约

可选 `table.attrs.tableCellMarginsTwips` 恰为 `{ "left": 整数, "right": 整数 }`，单位 twip，每项 0–31680；界面使用 pt、0.05 pt 精度。整对省略和显式 `0` 不同：省略保留既有模型、编码及默认样式路径；显式零保存为零，不能当成缺省。null、部分对象、多余键、字符串、布尔、浮点、负数、越界及其他节点上的属性均拒绝。

- 既有几何检查使用缺省左右各 108 twip；这不是对任意外部文件缺省值的推断，也不借本轮重写旧无属性编辑/打印 CSS
- 自有模型中显式 108/108 与省略仍可区分；外部源经证明为 108/108 时沿用旧的省略表示，避免改变旧导入输出
- 每列实际作者网格宽度必须严格大于左右边距之和，包括没有显式段落缩进的单元格。自动表格仍使用现有页面感知的明确规范化网格，不推断原始自动列宽
- 有显式段落缩进时，再从列宽减去这对边距，检查首行和后续行均保留正宽度、悬挂不伸出单元格正文区。缩小页面/列宽、增加列或改边距造成不适配时，整次候选拒绝，不改正文、草稿或撤销历史
- 该检查是行框约束，不保证长词、字体字形、自动换行、分页或所有边框都落在页面正文区

默认边距操作删除整对属性。新增属性只用于顶层表格；旧没有该属性的嵌套/列表路径不因此获得新几何承诺。无该属性的 V1/V2 导出必须保持历史整文件字节；不升级 profile、不更改全局兼容模式或无关表格/段落。

## 左边距会影响边框还是文字

本应用维持既有旧兼容基线。显式表格左缩进仍是文字边缘参照；在这个受限模型中，边框偏移为 `表格缩进 − 左单元格边距`。因此改左边距可移动边框而保持名义文字起点；表格未设显式缩进时，边框位置不作该补偿，文字随边距移动。居中/右对齐仍独立处理。DOCX 中写入统一 `tblCellMar/left/right`，不会篡改单元格段落自身缩进。

页面适配保留既有保守的“表宽 + 表格缩进”检查，不把它说成边框完整包含证明。旧模式显式零缩进的左边框可向左伸出一个左单元格边距；新增边距后不再固定为 108 twip。

## 外部 DOCX 的有界证明

几何审计、实际 OPC main/styles/settings 与正文转换继续使用同一个有界源快照；表格顺序、行列形状与转换结果交叉核对，另存禁止覆盖源文件和已有目标。

新非 108/108 的保留路径要求左右两边均有明确物理 `left/right`、非负整数 `dxa` 证据。可由显式选中的表格样式 basedOn 链、直接表格默认值和直接单元格覆盖逐分量组合；所有单元格最终必须是相同完整的一对。单元格等值覆盖可归并到表级，原 XML 语法位置不承诺逐字保留。未声明的一边不能凭消费者缺省或编辑器 108 自动补齐。

隐式默认样式的自定义边距、活动条件自定义边距、逐格不同值、逻辑自定义 start/end、百分比、未知单位、冲突别名/命名空间、重复、错误包装、模糊样式引用和不能证明的继承不进入保留子集。既有已证明的 108-twip 逻辑别名路径仍保留，不能借此支持自定义逻辑边距。上下边距、边框外观等继续按既有提示规范化，不是本功能的编辑能力。

没有位置/单元格段落缩进保真依赖的普通旧源，在新边距证明失败时继续既有明确的单元格格式规范化路线；不把这些源改称边距保持。直接表格缩进或有效单元格段落缩进需要完整边距证明，失败仍只读。固定表格显式样式继承的零缩进可配合已证明的边距；自动表格原有继承零缩进的规范化分支不被本轮偷偷改成新的位置承诺。

## 现代缩进仍拒绝

没有把 Word compatibilityMode 15 切换成全局导出设置，也没有新增未经证明的 border-reference 模型。新独立 LibreOfficeDev 控制实验发现：把现代 `tblInd` 简单加左边距后导出旧模式，0.5 pt 边框下仍有约 0.25–0.5 pt 的系统性文字/边框位移；零边距还受半边框最小距离影响。四种边框宽度的控制实验表明补偿依赖消费者对边框的处理，不能硬编码一个“魔术偏移”来声称通用 Word/WPS 保真。因此现代直接缩进和固定表格现代继承缩进仍拒绝，未知模式/重复或不明确 settings 保护不变。

未作缩进保持承诺的现代普通表格若保留边距数值，仍有既有边框/布局规范化限制；其消费者位置差异单独记录，不能计为源/输出位置相等。

## 独立文件与验证边界

`scripts/check-word-table-cell-margins.py` 使用独立 python-docx/OOXML 构造与读取，验证实际导入、边距编辑后导出、精确宽度/边距、完整可信模型、草稿/包篡改、原件哈希与禁止覆盖。LibreOffice PDF 分别测量外边框、列线和单元格文字；适配的受控旧兼容源/输出与独立编辑参考使用严格坐标对照。现代不兼容实验作为拒绝理由保留，不放宽误差阈值假装等价。

原始固定上游文件与自制定向样本分开。七表 `table-indent.docx` 仍包含逻辑自定义边距、现代模式、不同不支持缩进单位、负值、页面适配及独立页码元数据问题；它仍是组合拒绝证据，不能只解决一个问题就称为支持。原件不改造为“真实正对照”，二进制不随仓库分发，来源与许可范围保留在各语料清单。

实际通过计数、最终 CLI 身份、报告路径、历史整包字节证据与复用 PDF 清单见 [REGRESSION.md](REGRESSION.md)。真实浏览器、Windows WebView2、本应用原生 PDF 与系统打印仍未验收；独立 LibreOffice 不是这些环境或 Word/WPS 的替代验收。
