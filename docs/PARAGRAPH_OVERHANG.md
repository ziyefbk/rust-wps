# 顶层正文段落伸入页边距

在已有物理 twip 缩进模型上，新增一个受限子集：**具有显式、完整且校验通过的页面尺寸与四边正文边距时**，顶层正文段落和标题可以使用负左右缩进，或让首行悬挂伸入页边距。不能伸出纸张，不自动增加页面属性、裁剪、缩放或调整数值。此功能不是一般性负缩进、任意 Word 文档或完整分页保真支持。

## 模型、编辑与输出

仍使用 `indentLeftTwips`、`indentRightTwips`、`firstLineIndentTwips`，三项均是 −31680–31680 的整数 twip。缺省、显式零、正负值分别保留；原模型版本与 profile 不变。左右使用 `w:left` / `w:right` 的有符号整数；首行正数与零使用 `w:firstLine`，负数使用绝对值 `w:hanging`。源 OOXML 的 `firstLine` / `hanging` 本身仍只接受非负整数，不顺带扩展字符单位、逻辑 start/end 或任意单位字符串。

设正文宽度为 W，页面左/右边距为 ML/MR，左/右缩进为 L/R，首行偏移为 F。须同时满足：

- 后续行左边缘 `L ≥ −ML`
- 首行左边缘 `L + F ≥ −ML`
- 共同右边缘 `R ≥ −MR`
- 后续行和首行都必须有正宽度：`L + R < W`、`L + R + F < W`

这是段落行框的物理边界证明，不是字体字形、长单词、斜体外伸、复杂文字塑形或所有换行均不会越界的证明。页边距可以减小，但若现有段落失去适配，整个候选事务拒绝；不会把负值钳制到零。清除页面属性同样重新校验，须先把相关缩进调回旧容器范围。

没有显式页面的 V1/V2 模型仍使用旧 9026 twip 正文宽度和原约束：左右不能为负，首行不能超出正文左边。这样不把旧 V1 打印和 DOCX 默认边距的历史差异当作新的物理证明。直接表格单元格保留原非负左右与容器内悬挂范围，即使根文档有有效页面也不能借用纸张边距；列表、嵌套容器和单图均不进入新子集。

编辑器沿用现有缩进控件、事务前校验、原子撤销/重做、草稿、标题/正文转换与不可变打印快照。pt 与 CSS 物理单位解析允许负左右值，最终许可仍取决于完整文档与实际容器。将带外伸的段落移入列表/单元格、缩小保护它的页边距、清除必要页面或单独重置使剩余行框失效的字段，均整次拒绝。默认值不会暗中补齐页面。编辑/打印沿用负 `margin-left` / `margin-right` 与 `text-indent` 声明；这不等于实际浏览器排版或原生打印已验收。

页面的纯校验常量/函数提取到独立 UI 模块，避免新缩进校验与页面事务模块循环引用；既有页面入口继续导出相同符号与规则。原无新属性及非负缩进的写出路径不新增部件、不改变 XML 次序。

## 外部 DOCX 的证明

同一有界源快照先通过现有单节页面/OPC/settings/样式审计，再向段落缩进审计传递已证明的页面。负左右声明或有效的正文左侧悬挂外伸，必须属于 `w:body` 的直接段落；不能借透明包装被读取器展开后，误认为原本就是顶层正文。保留有效默认值、活动样式链和直接格式的分量继承，转换后的文字顺序与三项值仍独立交叉核对。

负左右源声明即使被更近的零/正值覆盖，仍保留来源标记；图片、表格和列表不会因为通用解析器开始接受有符号整数而得到新的许可。实际使用的编号层级/覆盖仍拒绝负左右值。旧单图段落的非负左右/首行悬挂规范化路线保持原样，不能把其警告说成新增文字缩进支持。没有相关新值的未使用样式维持既有处理。

多节、缺失/不完整或不支持的页面、RTL/镜像、字符/逻辑单位、自定义制表位、未解析的活动继承，以及同一声明同时设置 firstLine/hanging 等既有拒绝继续有效。已拒绝的无页面悬挂外伸可能更早在兼容性审计中报告缩进风险；这是诊断阶段前移，不是新增拒绝类别。表格普通正文、单图和页/列分页的旧路径由专项及历史响应重放分别核对。

## 真实原件与独立验证

未改造原件是 LibreOffice/core 固定 revision 的上游回归文件 `indents.docx`，来自既有 [语料清单](../scripts/paragraph-indentation-corpus.json)，不是用户生产文档。11,553 字节，SHA-256 `d62a3e3162a737cbe45e21fe544f5dc845e8cdc621bd8a2e3b7e8dcfed52386d`。五个段落用于行框计算的左/右/首行值依次为缺省、(−1134,0,0)、(−1134,0,567)、(−567,0,−567)、(1134,0,−567)；纸张 11906×16838 twip，左右边距各 1417，最左行框仍离纸边 283 twip。

旧版本导入只有缩进阻断。新版本保留原文字、段落及有效缩进后另存副本，并使用独立 python-docx / XML、完整可信模型重开、每文件新 LibreOffice profile 的 PDF 物理坐标和图像对照核验。实际前端事务生成的编辑/撤销/重做/标题转换/粘贴模型也交给独立消费者。合成边界与篡改件单独标记，不计为更多真实原件。

具体命令、通过数量、文件身份、旧字节/响应变化和可见差异见 [回归记录](REGRESSION.md)。旧 [段落缩进](PARAGRAPH_INDENTATION.md) 文档继续定义未扩展部分；旧 checker 的负值拒绝预期属于历史版本，不通过改写旧报告来宣称新结果。
