# 行内图片显示尺寸

本轮让受支持 PNG/JPEG 的显示宽高贯通正文图片选择、数值编辑、撤销/重做、草稿、DOCX 导出及可信模型重开。保留的是明确的图片显示框和嵌入媒体字节，不是完整源页面布局、Word/WPS 像素一致或任意图片段落格式。后续 [单图段落](IMAGE_PARAGRAPHS.md) 扩展了受支持的间距、对齐和有限基线字体。原件不改写，导出仍必须另存新文件。

## 模型与编辑

- 图片节点新增可选的 `displayWidthEmu` / `displayHeightEmu`，必须同时出现且为正整数；显式 `null`、只给一边、字符串、小数及错误节点位置均拒绝
- 1 inch = 914400 EMU，1 pt = 12700 EMU，96 DPI CSS 下 1 px = 9525 EMU。宽上限 5715000 EMU（450 pt / 600 px），高上限 7620000 EMU（600 pt / 800 px）；该上限适合当前 A4 内容区，不能理解为原始文件的页面设置已恢复
- 首版只支持文档根下的正文图片。表格、列表中的图片仍可保持旧无尺寸模型，但不允许新显式宽高；任意光标、多选文字或其他节点不能误改图片
- 工具栏按 pt 编辑。能精确换算的十进制值直接使用；任意整数 EMU 可用 `95251/12700` 这样的精确 pt 分数输入/显示。不通过四舍五入偷偷改变导入宽高
- “保持比例”按当前框比例联动另一边，计算结果四舍五入到最近 1 EMU；超过另一边上限时拒绝。“恢复原始比例”以媒体像素比例调整当前框，必要时缩小至支持上限；不改媒体字节。“重置尺寸”同时去掉两项属性，恢复旧默认布局
- 一次尺寸应用/恢复/重置是一次撤销；修改前检查选区身份、保存锁、节点/文字/草稿预算，以及既有最多 100 张、每张 8 MiB、合计 20 MiB 的媒体限制。异步图片读取与原始比例解码绑定原文档及原选区，迟到结果不能改到另一张图片
- Tiptap 的旧 `width` / `height` 像素字段仍不属于支持模型。HTML 只接收完整有效的自有 EMU 元数据；普通 HTML 尺寸不升级成已审计几何。显式尺寸使用固定 CSS 宽高和 `object-fit:fill`，不会被旧 `height:auto` 或响应式最大尺寸悄悄改变；打印快照保留相同声明

省略新属性时，历史 V1/V2 编码部件字节保持不变；无尺寸图片仍沿用旧像素尺寸、600×800 px 限制和旧布局。重置可能改变当前图片大小，这不是恢复导入时的原始尺寸。旧图像数据/模型不会自动升级。

## 外部 DOCX 的证明边界

审计与转换读取同一份至多 64 MiB 的快照。ZIP 条目/展开上限、OPC 主文档、实际图片关系、类型、媒体 MIME、签名和字节哈希都参与核对。图片必须位于正文顶层单独段落，只含一张行内 PNG/JPEG；主显示框 `wp:extent` 和图片变换框 `a:xfrm/a:ext` 必须明确、唯一且完全相等，偏移为显式零，形状为矩形。

允许经审计的无效果元数据，如零 `effectExtent`、空/全零 `srcRect`、无填充边框、锁定属性、空效果列表、已知 `useLocalDpi` 元数据及同段成对非视觉书签。图片像素数据不能通过声明为另一种 MIME 蒙混；关系重复、丢失、外链或路径/命名空间歧义拒绝。

以下保持只读，不自动丢弃后声称尺寸保真：

- 浮动/锚定对象、VML、OLE、文本框、混合文字/制表符/换行、多图同段、超链接内图片、列表和单元格图片
- 裁剪、旋转/翻转声明、相对尺寸、非零偏移/环绕距离、效果、非矩形几何、不匹配/缺失/重复/非法 extents、未知绘图扩展
- 可能变换图片的段落/文字方向、东亚组合布局、字符缩放和上/下标，包括活动样式继承；不能仅因 `a:xfrm` 没有旋转就推断安全
- JPEG APP1 元数据（保守地包括 EXIF/XMP，即使 EXIF 方向为 1）、PNG eXIf 与 APNG 动画；未知方向解释不能在浏览器与 Office 之间冒充一致。显式尺寸同时拒绝截断的媒体容器及结束标记后的多余数据；像素头同时限制每边不超过 20000、总计不超过 4000 万像素，完整像素有效性仍由导出解码器校验

转换后再次按源顺序核对每张图片的 MIME、SHA-256 和 IR 宽高，数量或身份不符即拒绝。固定解析库会把图片从其空段落提升为相邻图片节点；只移除该图片紧前方明确为空的占位段落，不合并真正的相邻空段落。回归包含前后/中间空段与相同字节不同宽高的重复图片。

本尺寸轮原先规范化源图片段落的对齐、间距和基线字体。后续 [单图段落](IMAGE_PARAGRAPHS.md) 保留受支持属性并分别提示剩余页面/段落规范化与缺省基线风险。因此不能从数值宽高相同推断整页排版一致。新显式导出将 `distT/B/L/R` 写为 0；独立 LibreOffice 实验发现省略它们会产生约 9 pt 水平位移。此修正只进入新尺寸分支，旧无属性分支保持字节兼容。
