# 正文 / 标题转换与输入

文字编辑器“正文 / 标题 1–3”下拉框、Ctrl+Alt+0–3 快捷键及段首 `# ` / `## ` / `### ` 输入规则现在逐段转换，修复原入口把段落格式重置为缺省的问题。原 Tiptap `setNode` 只在选区两端同属一个段落时复制属性；本应用不修改依赖，这些入口共用 `ui/word-block-type.ts` 中独立构造的候选事务；`ui/word-block-type-interactions.ts` 替换段落 / 标题节点的实际快捷键和输入规则，不创建重复节点或保留危险的旧回退。

## 保留范围

- 每个选中正文 / 标题分别保留对齐、段前、段后、倍数行距、左右缩进、首行 / 悬挂缩进，包括明确零、缺省值和不同段落的不同值
- 仅更改段落种类和标题级别，保留文字、硬换行、Unicode、字符样式与链接、光标待输入格式、文档默认样式和页面 / 表格几何
- 支持当前段落、正向 / 反向文本选区、整段节点选区、全选和表格单元格选区；选区恰好止于下一段文字起点时不修改下一段，实际选中的空段仍转换
- 一次操作是一个撤销步骤；后续正文 / 标题转换和输入分别撤销。重复选择当前类型没有新草稿 / 历史事务
- 固定值仍是固定值，不重新推断已导入的命名样式身份或上下文间距关系

未显式设置的字号、粗体及默认段距继续随正文 / 标题样式改变，这是类型切换的预期效果。保留显式格式不代表字体替代、自动分页或完整 Word / WPS 版式不变。

## 原子拒绝和边界

列表项首个块必须是正文段落。选区包含这类段落而请求标题时整次拒绝，其他可转换段落也不改变；不会解除列表、重排或偷偷只改一部分。列表后续段落可在父结构允许时转成标题，再转回正文；转换为正文保留列表容器。

图片和手动分页符不改动，只有原子对象的选区没有操作。若任何选中文字块或活动属性不能无损表达、父结构不允许、已知间距 / 缩进 / 页面约束不满足，或候选超出节点、深度、正文和草稿保存预算，整次候选被丢弃。候选与调用方事务隔离，失败不污染文档、选区、待输入格式或历史。这里的前端校验不替代 Rust 导出器的完整模型校验。

## 快捷键与标题标记

- Windows / Linux 为 Ctrl+Alt+0–3；保留 Tiptap 的 Mod 映射，macOS 对应 Cmd+Alt。1–3 设置相应标题；实际选中块全部已是同级标题时切回正文。0 始终请求正文；混合级别设为请求级别
- 使用与工具栏相同的块集合判断切换，包括反向选择、下一段文字起点排除及多单元格选择；先同步尚未送达的 DOM 选区。保存 / 打印 / 离开 / 暂停、只读或组合输入期间不执行
- 在正文或已有标题段首输入 `# `、`## `、`### ` 时，仅删除匹配的标记，保留尾部文字、字符 marks 和待输入格式；类型转换和标记删除在完整候选校验后一起提交。失败不提前删除标记，普通待输入空格仍可写入
- 保留 Tiptap 的实际输入规则生命周期、代码标记排除、完成组合输入后的检查及 Enter / 空白匹配。带显式缩进段落的 Tab 仍受既有制表位保护，不能用标题规则绕过；普通粘贴事务不主动触发标题规则
- Backspace / `undoInputRule` 恢复原段落与字面标记 / 触发字符。默认自动补尾段插件保持启用；输入规则的历史元数据合并同一次转换所追加的真实步骤，撤回时移除本次自动补出的尾段，保留事先已有尾段。随后输入或选区变化正常结束可撤回窗口，不复活旧元数据
- 标题转换与后续输入分开撤销。Tiptap 会先提交触发文字，再提交转换；普通 undo 可以先撤回转换恢复标记，不假称整个输入过程只有一个事务

`tests/ui/word-block-type-upstream.spec.mjs` 的 8 项保留为未包装依赖的特征对照：原始回调仍会清空七字段，但这些回调已不再作为本应用的标题 / 正文入口注册。未经包装的 `setHeading` / `setParagraph` 等程序命令仍保留上游行为，本轮不宣称全部命令已替换。

## 真实插件与证据边界

无浏览器测试注册整个实际扩展管理器插件链，包括默认尾段、历史、输入规则和新的历史边界。快捷键用普通事件对象调用真实 keymap，输入用真实 `handleTextInput`，组合结束用真实钩子 / 计时回调，普通粘贴用带粘贴元数据的事务；这些检查覆盖真实源代码路径，但不是浏览器按键、系统剪贴板、中文 IME 或原生 WebView 验收。

独立 DOCX 驱动显式记录自动尾段；以原输入块范围操作时不把自动新尾段计成原件文字。新尾段的缺省样式和没有直接段落属性由独立读取器核对。原文件不修改，真正上游原件与自制源分别登记。
