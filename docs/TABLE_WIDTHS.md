# 简单矩形表格的固定列宽

支持未合并、非嵌套矩形表格的固定列宽。工具栏按当前单元格所在列设置宽度，对所有行生效；恢复自动宽度作用于整张表。没有拖拽手柄、百分比宽度、自动适应内容算法、合并单元格、行高或边框编辑。整体对齐与有限左缩进见 [表格位置](TABLE_POSITION.md)。

## 模型与单位

- 可选 `table.attrs.columnWidthsTwips` 是与列数一致的正整数数组；每列 1–31680 twip，总和不超过 31680 twip（1584 pt）
- 这是产品资源/数值边界，不是页面宽度限制；无显式页面属性的旧模型中超出正文区的表格可能溢出，尚无 Word/WPS 自动分页布局
- 输入单位为 pt，精度 0.05 pt；模型整数 twip 保留到草稿、DOCX 和可信模型重开
- 属性省略时保留旧的等宽/自动行为；外部 JSON 的 null、浮点、字符串、零、负数、数量不符和超限均拒绝
- Tiptap 单元格 `colwidth` 是 CSS 单位，不能当作 twip。固定列宽只以表级数组为规范来源；渲染按 15 twip = 1 CSS px 换算
- 固定列宽不支持任何嵌套表格组合；没有固定属性的历史嵌套模型不因此改变其旧版编码

首次从自动切换到固定时，无页面属性或定位表格先把 450 pt（9000 twip）按列数均分；有显式页面的普通未定位自动表格从当前规范化作者宽度按列数分配，除不尽的整数余量从首列起分配，再应用当前列输入值；不是测量或推断屏幕当前宽度。新增列复制相邻选中列的宽度，超出总和上限时拒绝。恢复自动清除整表固定数组。

表格结构操作须在一次事务内维护数组和矩形内容，失败不改正文或历史。删除列同时删除对应宽度；增加列、设置宽度和恢复自动均可一次撤销。宽度数值输入不会改变段落间距、文字样式或单元格内容。

## DOCX 路线

导出显式 `w:tblLayout type="fixed"`、总宽 `w:tblW type="dxa"`、逐列 `w:tblGrid` 和每行一致的 `w:tcW`。没有新属性的 V1/V2 文档保留历史部件字节；固定宽度不升级 profile。自有文档仍须通过模型、哈希、部件集合和重编码一致性校验，不能用外部重新导入代替可信重开。

外部 DOCX 只有在原始布局信息证明为受支持固定布局时才保留列宽。单独出现 `tblGrid` 不能证明固定布局。导入前审计与转换读取同一有界源快照；源文件不修改，导出拒绝覆盖。

受支持的固定子集为直接、唯一的 fixed 布局声明、正整数网格宽度、每个单元格一致的 dxa 宽度，以及匹配网格总和的 dxa 表宽。常见的自动零表宽或省略表宽，在其他固定证据完整时允许。未显式 fixed 的普通自动表格仍按旧路线规范化，并明确提示不保留源列宽。

不支持/模糊的固定几何、百分比、合并、浮动和嵌套布局拒绝编辑转换；有限表格对齐与缩进按 TABLE_POSITION.md 的独立语义证明处理。活动表格样式链中的几何声明保守检查，无法证明的样式继承布局不宣称保留；无关未使用模板样式不阻止普通文档。该审计不等于完整表格样式、单元格边距、分页、双向文字或 Word/WPS 视觉保真。

## 验证范围

核心测试覆盖整数/总和/列数边界、嵌套和合并拒绝、草稿、固定 XML、可信重开、模型/包篡改以及失败不覆盖。无浏览器前端测试覆盖 schema、单位、事务、选区、结构与撤销；这些不证明实际焦点或浏览器布局。

独立脚本由 python-docx 生成有固定预期的定向文件，核对输入、编辑后输出的 XML 和 python-docx 读数，以及可信模型完全相等。固定 Apache POI 原件另列来源和 SHA-256，不把自制样本称为真实用户生产文件。`SampleDoc.docx` 只作为无表格的旧兼容正对照；未经修改的 `table-indent.docx` 有 7 张实际固定表格，包含不支持的缩进声明，专门验证明确拒绝，而不是支持往返的证据。LibreOffice PDF 探针只证明该独立 DOCX 消费者的受控边框位置/文字换行，不是简文打印、Windows WebView2、Word/WPS 版式等价证据。

```text
cargo test --locked --test word_table_widths --test word_table_import
npm run build
npx playwright test tests/ui/word-table-width-model.spec.mjs
python scripts/check-word-table-widths.py --cli target/debug/rust-wps --render --corpus tmp/corpus/SampleDoc.docx --table-corpus tmp/table-corpus/table-indent.docx
```
