# dot 接手说明

PDF 只在有界源校验之后捕获提取器普通 unwind：严格模式明确错误，预览模式为空正文 / 真实字节数 / panic-specific `text_error`。两份未改造 CMap 失败原件经公共预览 API 与实际 PDF.js 正文恢复核对；不要将其称为 Rust 成功提取或真实页面验收。原 13 项快照检查保留，新增 10 项策略 / 边界检查；详见 [PDF_PANIC_RECOVERY.md](PDF_PANIC_RECOVERY.md)。worker 硬故障、abort / 资源问题和后续路径重开的会话身份仍单独处理。

PDF.js 正文拼接保留显式空白 / 空 EOL，仅对证明为同基线水平 LTR 的连续片段直连；其他几何保守分隔。真实论文四条字面短语和连续字体 / 几何反例已核对，原页末裁剪及 UTF-16 代码单元上限不变。详见 [PDF_TEXT_ASSEMBLY.md](PDF_TEXT_ASSEMBLY.md)；实际 main.ts 重提取 / 查找仅经 DOM 运输替身验证，不算浏览器 / 原生验收。

PDF 核心使用已打开 reader 的 64 MiB 有界快照，签名、实际字节数及内存提取器共用同一缓冲区；不再在提取时重开路径。13 项确定性测试覆盖替换 / 删除路径、源增长 / 缩小、读取上限与严格 / 预览错误策略。实际原件及独立提取结果见 [PDF_SOURCE_SNAPSHOT.md](PDF_SOURCE_SNAPSHOT.md)；`read_current_pdf` 的后续路径重开仍是独立未解决的会话身份问题，不要扩大本轮保证。

简单表格新增逐格直接 RGB 底色与独立局部自动文字色；显式文字 RGB 优先，底色 / 自动模式分别重置，保持撤销、草稿和可信 DOCX 重开。源颜色须经过直接路径、实际活动样式 / 主题及文字一致性核对；主题底色转换为固定 RGB，未证明路径保留有提示的旧规范化。编辑器 / 打印的黑白对比仅是近似预览，详见 [单元格底色与自动文字色](TABLE_CELL_COLORS.md)，不承诺原自动列宽或整页保真。

已存在的真正空标题在首文字位置按 Backspace 退回正文时，保留对齐 / 间距 / 缩进与空行基线字体；输入规则撤回仍优先，其他合段 / 列表 / 选区行为保持原路径。完整插件链与独立 DOCX / 有界 PDF 对照见 [正文与标题转换](BLOCK_TYPE_CONVERSION.md)，实际浏览器 / 原生按键仍未验收。

正文顶层真正空段落新增有限 Latin 基线字体保留，包含默认 / 样式 / 直接段落标记解析、空段状态与重置、撤销 / 草稿及 DOCX 可信重开。首次输入或粘贴内容后原子结束该空行覆盖，普通文字格式不隐式改变；不插入伪空格。实际源字体 / 独立行框证据及表格 / 列表继承等边界见 [空段基线字体](EMPTY_PARAGRAPH_FONTS.md)，浏览器 / 原生打印仍未验收。

简单正文顶层表格新增逐行最小高度与逐格顶部 / 居中 / 底部对齐，保留默认 / 显式零 / 混合状态、原子撤销、草稿、DOCX 可信重开与打印快照。源必须通过直接路径、活动样式和行格文字身份核对；精确行高、继承 / 条件垂直几何及非零上下单元格边距等仍拒绝。真实未改造样本与独立纵向测量见 [表格垂直布局](TABLE_VERTICAL_LAYOUT.md)；原自动列宽仍规范化，实际浏览器 / 原生打印未验收。

## 目标和当前状态

这是 Windows 本地离线办公原型，Rust 核心、Tauri 桌面壳、Tiptap 编辑器。开发顺序为 **DOC/DOCX/PDF → Excel → PPT**。三阶段已有可运行的受限原型，完整 Office/WPS 兼容仍未完成；不要把文字提取或 ZIP 解析成功当作版式和编辑兼容。各格式的能力和缺口以 [ROADMAP.md](ROADMAP.md) 为准。

本轮新增同样式上下文间距的有界固定值转换：源默认/叶样式身份、true/false继承和完整段落/表格/单元格顺序经核对后，解析为现有段前/段后值。原样python-docx编号/项目符号模板现可通过；导入前明确提示动态命名样式与重排关系不保留。不加伪上下文开关，非对称正间距、名称/缺省身份歧义及整文档未证明内容仍拒绝，见 [上下文间距](CONTEXTUAL_SPACING.md)。

本轮新增简单正文顶层表格的统一物理左右单元格边距：可选完整整数 twip 对、显式零、当前表格控件、撤销/草稿、DOCX 可信重开和共享打印声明。每列须保留正内容宽度，段落缩进按实际边距复查，缩窄候选原子拒绝；源按直接/显式样式/统一逐格覆盖证明，见 [水平单元格边距](TABLE_CELL_MARGINS.md)。现代缩进仍拒绝：独立消费者显示简单“加左边距”仍差 0.25–0.5 pt，补偿依赖边框，未硬编码消费者偏移或全局更改兼容模式。原始七表文件仍有多重独立阻断。

正文、标题和简单表格单元格新增有限左右缩进与首行/悬挂缩进，使用整数 twip，保留默认/显式零、混合选区、撤销、草稿与 DOCX 可信重开。缩小页面/列宽造成行框不适配时整次拒绝；活动复杂方向、字符单位、自定义制表位与模糊继承不静默丢失。普通列表与单图的既有明确规范化路径仍保留，不能把文字缩进承诺套用到图片。范围和独立真实文件/消费者证据见 [段落缩进](PARAGRAPH_INDENTATION.md)，实际浏览器与原生打印仍未验收。

本轮新增受审计的单节页面尺寸/正文边距和共享打印几何，旧无属性模型保持原样。纸张范围 A4/Letter/A5 横纵向、整数 twip；页面缩小造成显式对象超限时拒绝；普通未定位自动表格按正文区明确规范化，见 [页面几何](PAGE_GEOMETRY.md)。

本轮新增正文单图段落的有效间距/对齐与有限 Latin 基线字体：图片专用段落样式修复小图行框，UI 选区控制、撤销/草稿、严格模型与可信重开贯通。缺省旧模型仍保留原字节，当时尚未覆盖源页面，后续单节子集见 PAGE_GEOMETRY.md；复杂混排仍不在承诺内，见 [单图段落](IMAGE_PARAGRAPHS.md)。

本轮新增受审计的正文行内 PNG/JPEG 显示尺寸、比例/重置、撤销/草稿、DOCX 与可信重开；媒体字节保持不变；后续单图段落扩展保留有限间距/对齐，整体排版仍未完整恢复。真实原始图片正对照、媒体方向限制、旧字节兼容与独立物理尺寸验证见 [图片尺寸](IMAGE_DIMENSIONS.md)。

本轮新增简单表格整体对齐与有限左缩进，默认/显式零、选区/混合、撤销/草稿、导出/可信重开贯通。独立消费者发现旧模式文字边缘参照与现代边框参照不同；导入按设置/边距/样式证明收窄，原始六表自动对齐有明确规范化正对照，原始七表缩进仍拒绝。详见 [表格位置](TABLE_POSITION.md)。

此前新增简单矩形表格的有限固定列宽：正整数 twip 数组、当前列数值设置、原子增删行列、撤销/草稿、固定 DOCX 读写及可信模型重开。源布局必须由同一有界快照中的明确 fixed/grid/tcW 证明，自动表格明确规范化；复杂或模糊几何拒绝。范围见 [固定列宽](TABLE_WIDTHS.md)。

本次新增段前/段后间距与倍数行距的选区/当前段落编辑、撤销、草稿及 DOCX 往返；包含列表/单元格，修复继承和自闭合空段丢失。外部 DOCX 有效缺省实体化为 0/0/240；可信自有模型与旧 DOC 路线不变。范围见 [段落间距](PARAGRAPH_SPACING.md)。此前已完成 Word 显式字体名从选区编辑、光标输入、撤销、草稿，到 DOCX 导出与外部导入的闭环。外部 DOCX 按脚本区分 ascii/hAnsi/eastAsia/cs 字体，处理有限主题字体语言；引用缺失的主题字体会警告。`standard-v2` 新文档默认样式与旧 V1 模型并存。字体名输入是字面值，最多 31 个 UTF-16 单元；本机字体不可用时由系统替代。旧 DOC 字体表尚未实现。

最近新增 [DOCX 附属内容保护](SIDE_STORIES.md)：以实际 OPC 关系及主 XML 引用阻止非标准名称的页眉页脚等内容静默丢失，IR 全六个页眉页脚字段再次检查。没有新增这些内容的编辑能力；最新本轮验证见 REGRESSION。简单固定列宽及有限表格对齐/缩进已接入；现代缩进参照、自定义单元格边距等仍规范化或拒绝，具体边界见 TABLE_POSITION。间距和固定列宽 UI/原生渲染验证仍需补齐。

工具栏、Ctrl+Alt+0–3 和段首 Markdown 标题输入规则已用同一应用候选事务逐段保留格式，包含切回正文、混合选区、标记删除、Backspace 撤回和自动补尾段历史；列表首段不转标题、不解除列表。仅替换应用入口，不修改 node_modules 或所有上游程序命令；详见 [BLOCK_TYPE_CONVERSION.md](BLOCK_TYPE_CONVERSION.md)。

在 Windows 安装 Rust、Node/npm、MSVC 构建工具和 WebView2。仓库根目录执行：

```powershell
npm ci
cargo test --locked --quiet
npm run build
npx playwright test
npx tauri build --no-bundle --debug
```

CLI 为 `target/debug/rust-wps.exe`，桌面程序为 `src-tauri/target/debug/rust-wps-desktop.exe`。UI 测试使用 Edge 与 `dist/` 的 Vite preview；**测试仍在运行时不要重建前端或桌面**。测试需要 `python-docx`、`openpyxl`、`python-pptx`、`pypdf` 等独立读取器；本机验证使用 Codex bundled Python。`tmp/`、`dist/`、`target/` 均不纳入 Git。

真实 DOC/DOCX 样本按 `scripts/corpus.json` 的来源和 SHA-256 下载，执行 `scripts/check-corpus.ps1` 和 `scripts/check-corpus-independent.py <输出目录>`；样本不随仓库分发。原生 PDF/字体检查需先执行 `npx tauri build --no-bundle --debug --features native-smoke`，再运行 `node scripts/native-word-font-family-smoke.mjs`；最后重建普通桌面程序。脚本需要 Windows 已安装 Courier New，证据写入忽略的 `tmp/native-word-font-family/`。

解析库 `vendor/office_oxide/` 是固定的 0.1.13 包，改动见 [vendor/README.md](../vendor/README.md)。不要用全目录 `cargo fmt` 重排其原始文件。改字体、样式或 DOC 分页时，核对两份补丁是否仍能 `git apply --reverse --check --directory=vendor/office_oxide`；DOCX 补丁可用 `python scripts/refresh-vendor-typography-patch.py` 从本地已核对哈希的 registry 原包重建。

## 优先继续的工作

1. **DOC/DOCX/PDF**：工具栏、快捷键与 Markdown 标题输入的格式保持已修复；有可用环境时补验真实按键、输入法、剪贴板、草稿及原生打印，不将无浏览器插件调用说成界面验收。未包装的上游程序命令仍保留特征对照。上下文动态命名样式仍未建模；有限正文空段字体已接入，复杂 / 多脚本空段与表格边框仍可能规范化。统一物理左右边距子集现已接入；现代缩进参照需要更完整的边框/单元格几何模型与多消费者证据，不能用一个 LibreOffice 半边框偏移代替通用语义。下一步优先扩大可证明的对象/段落布局与真实文件覆盖，不直接移除现代、复杂或模糊继承保护。继续扩大有证据的页面/对象布局子集，当前单节纸张与边距已覆盖有限 A4/Letter/A5；扩大有来源和授权的真实文件语料；独立比对 Word/WPS 的段落、分页、图片、表格和视觉结果。处理复杂样式、页眉页脚、域、浮动对象、主题字体动态关联，以及本机缺字回退。DOC 二进制字体表尚未解析；PDF 尚无正文编辑、注释和页面操作。原生中文输入法、系统剪贴板/对话框与打印的验收不足。
2. **Excel**：在现有 XLSX 稀疏编辑、数字格式、有限公式、工作表及 XLS 只读基础上，补筛选、字体/边框等样式、完整依赖与增量重算、更多外部文件转换；保持原文件安全和公式缓存身份。
3. **PPT**：在现有 PPTX 文本/图片/页操作/播放/PDF、PPT 旧格式只读基础上，补基本形状、混合对象层次与模板继承，再扩大旧版和复杂对象兼容。

无新间距属性的 V1/V2 所有编码部件必须保持历史字节；有新属性时才增加最小 settings 部件，维持模型哈希/重编码保护。不要把 `import-docx` 当可信模型重开，使用 `read-docx-model`。

新增格式能力时，先定义受支持模型和拒绝边界，再用真实文件与独立消费者验证导出、重开、原件不变。现有具体回归结果、限制和原生证据位置见 [REGRESSION.md](REGRESSION.md)。
